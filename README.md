# 🧠 DemenCure

### A Web-Based Cognitive Care & Memory Support Platform

DemenCure is a web-based cognitive care platform designed to provide users with a simple and interactive environment for cognitive activities, memory exercises, progress tracking, and personalized reminders.

The platform combines a clean user interface with Firebase Authentication and Cloud Firestore to provide authenticated user accounts and persistent user data.

🔗 **Live link:** https://demencure.vercel.app/

🔗 **GitHub Repository:** https://github.com/ShamikDas-Dev/DemenCure


---

## 📌 Overview

DemenCure is designed around the idea of making cognitive care activities more accessible through a simple web application.

The platform provides:

- Secure user authentication
- Personalized user dashboard
- Cognitive memory games
- Sequence-based cognitive activities
- Progress tracking
- Personalized reminders
- Cloud-based user data storage
- Responsive and accessible interface

The application is built using standard web technologies and Firebase services, making it lightweight and easy to deploy.


---

## ✨ Features

### 🔐 User Authentication

Users can create an account and securely log in using Firebase Authentication.

The authentication system handles:

- User registration
- User login
- Email verification
- Authentication state management
- Logout
- Protected dashboard access


### 👤 Personalized Dashboard

After authentication, users are provided with a personalized dashboard containing:

- User name
- Email address
- Age
- Personalized welcome message
- Profile information
- Access to cognitive activities
- Reminders
- Progress tracking


### 🧠 Memory Game

The platform includes an interactive memory game designed to provide a simple cognitive activity.

Users can interact with the game and use it as part of their cognitive activity routine.


### 🔢 Sequence Game

DemenCure also includes a sequence-based cognitive activity where users can test their ability to remember and reproduce sequences.


### 📊 Progress Tracking

The progress section allows users to view their cognitive activity and game performance.

This provides a centralized place for users to monitor their activity and performance over time.


### ⏰ Reminders

The reminder section is designed to help users keep track of important activities such as:

- Medicines
- Water intake
- Daily activities
- Other important reminders


### ☁️ Firebase Cloud Database

User information is stored in Cloud Firestore.

The application associates user data with the authenticated Firebase user ID, allowing each account to access its corresponding data.
